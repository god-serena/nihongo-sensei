# Implementation Plan — Task 6.2: Audio Visualizer

Build `VoiceVisualizer.vue` — a real-time microphone waveform display component.

---

## Component Contract

**Location**: `src/components/VoiceVisualizer.vue`

**Props:**
| Prop | Type | Default | Description |
|---|---|---|---|
| `active` | `Boolean` | `false` | When `true`, starts mic capture and animates the waveform |
| `barCount` | `Number` | `32` | Number of frequency bars to render |
| `color` | `String` | `'#6366f1'` | Bar fill colour (Tailwind indigo-500) |

**Emits:**
| Event | Payload | Description |
|---|---|---|
| `error` | `{ message: String }` | Emitted if `getUserMedia` is denied |

**Behaviour:**
- On `active = true`: calls `navigator.mediaDevices.getUserMedia({ audio: true })`, creates an `AudioContext` + `AnalyserNode`, and drives a `<canvas>` animation loop via `requestAnimationFrame`.
- On `active = false`: disconnects the stream, closes the `AudioContext`, and cancels the animation loop.
- Renders a `<canvas>` element with a bar-chart style frequency visualizer.

---

## Pinia Store

**Location**: `src/stores/audio.js`

Manages mic/push-to-talk state shared across components:

```js
export const useAudioStore = defineStore('audio', () => {
  const isListening = ref(false)
  const isSpeaking = ref(false)  // TTS playback in progress
  function startListening() { isListening.value = true }
  function stopListening()  { isListening.value = false }
  return { isListening, isSpeaking, startListening, stopListening }
})
```

`VoiceVisualizer` binds its `active` prop to `audioStore.isListening`.
