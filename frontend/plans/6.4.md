# Implementation Plan — Task 6.4: RAG & Summary Dashboard

Build `DocumentManager.vue` (file upload and chunk tracking) and `SessionSummaries.vue` (structured summary viewer).

---

## DocumentManager.vue

**Location**: `src/components/DocumentManager.vue`

**Responsibilities:**
1. Drag-and-drop or click-to-browse file upload (`.txt`, `.md`, `.pdf`).
2. POST the file to `/api/rag/upload` via `api.uploadDocument()`.
3. Display a list of uploaded documents with their chunk count.
4. Show upload progress and success/error feedback.

**Pinia Store**: `src/stores/documents.js`
```js
export const useDocumentStore = defineStore('documents', () => {
  const documents = ref([])   // { id, title, chunk_count }
  const uploading = ref(false)
  const error = ref(null)
  async function upload(file) { ... }
  return { documents, uploading, error, upload }
})
```

**Template:**
- A styled drop zone (`dragover` / `drop` events).
- A hidden `<input type="file" accept=".txt,.md,.pdf">` triggered by the drop zone click.
- A list of uploaded documents rendered as cards with title + chunk count badge.
- A spinner/progress overlay while `uploading = true`.

---

## SessionSummaries.vue

**Location**: `src/components/SessionSummaries.vue`

**Responsibilities:**
1. POST to `/api/summaries` to generate a new summary for the current session.
2. Display the structured summary (topics list, vocabulary table, mistakes list).
3. Supports multiple summaries per session (stacked cards).

**Pinia Store**: `src/stores/summaries.js`
```js
export const useSummaryStore = defineStore('summaries', () => {
  const summaries = ref([])   // { id, summary: { topics, new_vocabulary, mistakes } }
  const generating = ref(false)
  const error = ref(null)
  async function generate(sessionId, messages, llmConfig) { ... }
  return { summaries, generating, error, generate }
})
```

**Template sections:**
- A **"Generate Summary"** button that calls `summaryStore.generate(...)`.
- A spinner while `generating = true`.
- Stacked summary cards, each showing:
  - **Topics**: bulleted list.
  - **New Vocabulary**: a 3-column table (term | reading | meaning).
  - **Mistakes**: expandable rows (original → correction + explanation).
