# Implementation Plan — Task 6.3: Chat & Controls

Build `ChatArea.vue` — the main conversation panel with message history, TTS audio playback, and a push-to-talk interrupt button.

---

## Component Contract

**Location**: `src/components/ChatArea.vue`

**Responsibilities:**
1. Display a scrollable chat history (user utterances + assistant responses).
2. Hold the push-to-talk (PTT) button that starts/stops mic capture.
3. Play incoming TTS audio chunks streamed over the WebSocket.
4. Show a **barge-in / cancel** button during TTS playback that sends `{type: "cancel"}` and interrupts the current response.

## Pinia Store

**Location**: `src/stores/chat.js`

```js
export const useChatStore = defineStore('chat', () => {
  const messages = ref([])          // { role: 'user'|'assistant', content: string }
  const partialResponse = ref('')   // accumulates streaming tokens
  const wsStatus = ref('closed')    // 'closed' | 'connecting' | 'open' | 'error'

  function appendToken(token) { partialResponse.value += token }
  function commitResponse() {
    if (partialResponse.value) {
      messages.value.push({ role: 'assistant', content: partialResponse.value })
      partialResponse.value = ''
    }
  }
  function addUserMessage(text) {
    messages.value.push({ role: 'user', content: text })
  }
  return { messages, partialResponse, wsStatus, appendToken, commitResponse, addUserMessage }
})
```

## WebSocket Wiring (in `ChatArea.vue`)

`ChatArea` owns the WebSocket lifecycle:
- On mount, calls `api.createSpeechWebSocket()` from `src/services/api.js`.
- Handles incoming messages:
  - `transcript` → `chatStore.addUserMessage(text)`
  - `token` → `chatStore.appendToken(token)`
  - `audio` → decode base64, create a `Blob`, play via `new Audio(url)`
  - `done` / `cancelled` → `chatStore.commitResponse()`, update `audioStore.isSpeaking`
  - `error` → display an error toast
- On unmount, closes the WebSocket cleanly.
