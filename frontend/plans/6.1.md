# Implementation Plan — Task 6.1: Vue 3 Setup

Bootstrap the Vue 3 frontend using **Vite** directly, then manually add Pinia, Vue Router, Tailwind CSS, and Vitest.

---

## Scaffolding Command

Run inside `/frontend`:

```bash
npx -y create-vite@latest . --template vue
```

This generates a minimal Vite + Vue 3 project in-place. No interactive prompts.

---

## Post-Scaffold Dependencies

```bash
npm install
npm install vue-router@4 pinia
npm install -D tailwindcss postcss autoprefixer vitest @vue/test-utils @vitejs/plugin-vue jsdom
npx tailwindcss init -p
```

---

## Configuration

### `tailwind.config.js`
```js
export default {
  content: ["./index.html", "./src/**/*.{vue,js}"],
  theme: { extend: {} },
  plugins: [],
}
```

### `src/assets/main.css` — prepend Tailwind directives
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

### `vite.config.js` — add Vitest block
```js
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  test: {
    environment: 'jsdom',
    globals: true,
  },
})
```

### `package.json` — ensure test script points to `vitest run`
```json
"scripts": {
  "dev": "vite",
  "build": "vite build",
  "preview": "vite preview",
  "test": "vitest run",
  "test:watch": "vitest"
}
```

## Project Wiring

### Vue Router — `src/router/index.js`
```js
import { createRouter, createWebHistory } from 'vue-router'
import HomeView from '../views/HomeView.vue'

export default createRouter({
  history: createWebHistory(),
  routes: [{ path: '/', component: HomeView }],
})
```

### Pinia + Router mount — `src/main.js`
```js
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import App from './App.vue'
import router from './router'
import './assets/main.css'

createApp(App).use(createPinia()).use(router).mount('#app')
```

### `src/App.vue` — minimal shell
```vue
<template>
  <RouterView />
</template>
```

## Centralized API Client — `src/services/api.js`

Per `AGENTS.md`: all API calls MUST go through this module — no raw `fetch()` in components.

```js
const API_BASE = import.meta.env.VITE_API_BASE ?? 'http://localhost:8000'
const WS_BASE  = import.meta.env.VITE_WS_BASE  ?? 'ws://localhost:8000'

export async function getHealth()              { ... }
export async function postChat(payload)        { ... }
export async function uploadDocument(file)     { ... }
export async function createSummary(payload)   { ... }
export function createSpeechWebSocket()        { return new WebSocket(`${WS_BASE}/ws/speech`) }
```
